MarkText 写博客，如虎添翼

我又让 Ghat GPT 帮我写了三组代码，它们的功能分别如下：

  1. 关闭 hugo serve 服务器，并运行 hugo 命令生成网站文件；

  2. 将 public 目录的网站文件复制到 Github 在本机的仓库目录；

  3. 给于代码2“复制文件的权限”，依次运行代码1和代码2。

我将第三个代码的快捷方式存放在 Windows 的开始菜单顶部，这里还有另外两个快捷方式，分别是用于「调用模板自动在指定文件夹生成当天的博客文件」和「双击后在后台默默运行 hugo serve 服务器」的代码。

有了这三个法宝，我无需再打开文件夹后执行一系列操作，只需专心在 MarkText 上写字，除了将 Github 本地仓库推送到云端时、每月初修改生成新文件的目录时需要打开 Github Desktop，其余情况操作都可以直接用菜单里的代码执行。

我的文档目录以月份为单位划分文件夹，故此，每月初要修改······

另外，我早些年已经在博客前辈那里得到了双击后自动将指定文件夹推送到云端 Github 仓库的代码，为什么这次对工作流的优化中，这么方便的工具反倒被优化啦？

  1. 我的 Github 仓库较多，用 Github Desktop 比较方便；

  2. 用代码上传文件，报错信息难以察觉，Github Desktop 则直观多了。

所以我不打算将 Github Desktop 踢出工作流。
